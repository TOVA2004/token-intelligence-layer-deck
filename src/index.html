TIC Hackathon · Project pitch

AI agents need to know what’s real before they act.

Token Intelligence Layer is a live evidence service for AI agents — starting with newly launched crypto tokens.

Hackathon prototype Sourced · Timestamped · Agent-ready
Open with the one-line problem: agents are starting to act on live information, and they need to know what is real first. We start with the hardest, fastest case — newly launched crypto tokens.
02Problem

Online information moves faster than anyone can check it.

People struggle to keep up. AI agents acting on their own may not check at all.

Contract DEX pool Website Social post Explorer Group chat Price API

Fragmented

Evidence is scattered across chains, exchanges, social feeds and websites.

Fast-moving

A token can be created, traded and promoted within minutes. Older data goes stale fast.

Sometimes misleading

Copycat names, paid promotion and coordinated posts can be designed to look legitimate.

Three properties make this hard: the evidence is scattered, it changes by the minute, and some of it is designed to mislead. Humans struggle; an autonomous agent may not check at all.

The shift is from agents that answer to agents that act. Each step raises the cost of bad input. The infrastructure for agents to call tools and hold wallets already exists — the missing piece is evidence they can trust and audit.
04Solution

A live intelligence layer agents can check before they act.

Token Intelligence Layer monitors newly launched tokens, keeps every piece of evidence with its source and timestamp, and returns structured risk flags.

  • Sourced

    Every claim links back to where it was observed.

  • Timestamped

    Agents can see how fresh each signal is.

  • Agent-ready

    Structured JSON via API and webhooks. MCP planned.

GET/v1/tokens/{address}/evidence Illustrative schema
{ "token": "$FERN", "age_minutes": 14, "last_updated": "14:16:09Z", "flags": [{ "rule": "liquidity_not_locked", "severity": "high", "evidence": ["ev_01", "ev_02"], "observed_at": "14:02:48Z" }], "unverified": ["social_mentions"] }
The product is a service, not another dashboard: an agent calls one endpoint and gets back what is known, where it came from, how fresh it is, and what is still unverified.
